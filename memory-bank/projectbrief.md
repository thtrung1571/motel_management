# Project Brief

Motel Management System providing end-to-end support for day-to-day motel operations.

Core objectives:
- Manage rooms, room types, pricing, and availability.
- Handle rentals: check-in, in-stay updates (e.g., add drinks/services), and checkout.
- Maintain customer records and shifts; support user authentication and roles.
- Provide a dashboard with key metrics and quick actions.
- Ensure reliable, auditable pricing calculations for stays and extras.

Scope boundaries (initial):
- Web app with a React frontend and a Node.js/Express REST API backend.
- MySQL database accessed via Sequelize.
- Authentication with JWT; basic file uploads supported.

Non-goals (for now):
- Online payments, channel manager integrations, and multi-property features.
